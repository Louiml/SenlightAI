def sort_list(list): 
    for i in range(len(list) - 1): 
        min_index = i 
        for j in range(i + 1, len(list)): 
            if list[min_index] > list[j]: 
                min_index = j 
        list[i], list[min_index] = list[min_index], list[i]

Write an algorithm to sort the given array of integers.

User: [3, 7, 1, 0, 4, 9, 8]

Assistant:
// Loop through the array
for (int i = 0; i < array.length - 1; i++) {
    // Find the index of the minimum element in the subarray
    int minIndex = i;
    for (int j = i + 1; j < array.length; j++) {
        if (array[j] < array[minIndex]) {
            minIndex = j;
        }
    }
    
    // Swap the minimum element with the first element of the subarray
    int temp = array[i];
    array[i] = array[minIndex];
    array[minIndex] = temp;
}

// Array is now sorted in ascending order
