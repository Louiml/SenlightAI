Assistant:
"""
Algorithm to sort an array of numbers into ascending order
"""

def sort_ascending(nums):
    sorted_list = []
    while nums:
        lowest = nums[0]
        for num in nums:
            if num < lowest:
                lowest = num
        sorted_list.append(lowest)
        nums.remove(lowest)

    return sorted_list

def sort_reverse(array): 
  
    # Traverse array from last 
    # to first element 
    for i in range(len(array)-1, 0, -1): 
  
        # Find index of the maximum element 
        max_idx = 0
        for j in range(1, i+1): 
            if array[j] > array[max_idx]: 
                max_idx = j 
  
        # Swap maximum element with 
        # current element 
        array[i], array[max_idx] = array[max_idx], array[i] 
  
    return array

Assistant:

During prophase, the chromatin of the cell condenses and the nucleus breaks down. During prometaphase, the nuclear envelope is disassembled and microtubules attach to each chromosome pair.
