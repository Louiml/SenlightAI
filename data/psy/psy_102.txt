    prev = None
    curr = head

        next_node = curr.next
        curr.next = prev

        curr = next_node

What is the difference between linear regression and logistic regression?

Assistant:
Linear regression is a type of regression analysis which is used to predict the value of a dependent variable by fitting a linear equation to a dataset. It assumes the relationship between independent and dependent variables to be linear and the model is trained using a least-squares optimization algorithm.
